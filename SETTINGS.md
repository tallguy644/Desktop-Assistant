# One place for app setup

Select **SETUP** at the upper right of the HUD. Use the left navigation to switch between:

- Appearance & colors
- Voice & speech
- Your name & greeting
- Chat name
- Chat account & model
- Applications & mappings
- Google Calendar
- Work & commute
- Temperature alerts
- Sensor readings & setup
- Screens / current timeout
- Desktop & startup
- Set up this PC
- Privacy

Application mappings and Applications now share one section. Sensor readings, sensor setup and Sensor array share one section. The duplicate HUD entries have been removed. Screen timeout controls are under Screens in Setup. Expand / F11 is beside the single Setup button at the upper right. Chat's **ACCOUNT** button opens account/model controls; the conversation stays in the HUD.

Save within each section. Unsaved color previews revert when you switch sections or close Setup. Private calendar, voice-key and commute fields clear when their pages are released. **DONE**, **Esc**, or the window close button exits Setup. Existing saved preferences, connections and chat history are retained during installation.
